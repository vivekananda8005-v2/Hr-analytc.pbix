# HR Analytics Dashboard – Power BI

## Project Overview
An interactive HR Analytics Dashboard developed using Microsoft Power BI to analyze employee and workforce data.

## Key Features
- Employee and workforce analysis
- HR KPIs
- Interactive charts and visualizations
- Filters and slicers
- Data cleaning and transformation
- Dashboard-based insights

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Excel
